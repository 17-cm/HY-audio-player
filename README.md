# 酒馆扩展音乐播放器

支持网易云音乐和汽水音乐双平台解析的播放器扩展。

---

## ✨ 功能

▸ 网易云音乐：单曲导入 / 歌单批量导入（建议每歌单不超过 20 首）

▸ 汽水音乐：单曲导入（分享链接直接解析）

▸ 播放模式：列表顺序 / 单曲循环 / 列表随机

▸ 显示模式：窄屏 / 律动 / 纯享

▸ 歌词显示：LRC 格式，支持渐变色

▸ 自定义外观：RGB 灯效 / 磨砂玻璃 / 背景图片 / 尺寸调节

▸ 一键缓存：刷新页面不失效

▸ 链接失效：自动刷新获取

▸ 通道检测：设置面板中一键检测接口可用性

---

## 📦 支持格式

**网易云**
· music.163.com/song?id=xxx（单曲）
· music.163.com/playlist?id=xxx（歌单）
· 163cn.tv/xxx（短链接）

**汽水音乐**
· qishui.douyin.com/s/xxxxxx/（分享链接）

---

## ⚙️ 操作说明

| 操作 | 说明 |
|------|------|
| 添加歌曲 | 点击「+」→ 选择平台 → 粘贴链接 |
| 隐藏播放器 | 扩展设置中切换 |
| 拖动播放器 | 点击顶部灵动岛拖动 |
| 律动模式 | 点击「𓆝」· 左侧拖拽 · 右侧双击返回 |
| 纯享模式 | 点击「𓆟」· 点击任意位置退出 |
| 自定义外观 | 点击「♡」进入设置面板 |

---

## 💡 提示

· 导入后点击「一键缓存」避免刷新失效
· 歌单建议分批导入（≤ 20 首）
· 导入时尽量不要开梯子
